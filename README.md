### 👨‍💻 About

I'm a final-year Computer Science Engineering student at Universidad Central del Ecuador, focused on **reliable backend systems and end-to-end products**. As a freelancer on a 3-person team, I build an **academic management system in production used by ~1,800 people**: Django REST APIs, a React + TypeScript admin app and SQL Server, deployed with Docker and Nginx on Linux. I also bring **3D and game development** as a creative differentiator.

- 🚀 **Production experience**: layered Django APIs, JWT + role-based access control, Celery/Redis jobs, and Moodle and Microsoft 365 integrations
- 🧩 **Backend-first mindset**: Django, FastAPI, Spring Boot and Quarkus; microservices, REST contracts and OAuth2/JWT
- ☁️ **Cloud & AI (current focus)**: Linux servers on Hetzner, simulation workloads on Google Cloud, preparing for **AWS Certified Cloud Practitioner**, studying generative AI (RAG, MCP)
- 📊 **Data & simulation**: ETL pipelines, PostGIS, Apache Spark and multi-agent simulation (GAMA)
- 🎨 **3D & games**: Rhino and Cinema 4D modeling, React Three Fiber on the web, Unity games
