### 👨‍💻 About

I'm a Computer Science student close to graduating, focused on **reliable backend systems and end-to-end products**. I design scalable microservice architectures, implement secure auth flows (OAuth2 / JWT), and turn raw data into useful visual insights with distributed processing. I also bring **UI/UX and 3D craftsmanship** as a differentiator — products that ship *and* stand out.

- 🧩 **Backend-first mindset** — microservices with Spring Boot &amp; Quarkus, REST contracts, OAuth2/JWT
- 📊 **Data &amp; Analytics** — ETL pipelines, MongoDB ingestion, distributed processing with Apache Spark
- 🎨 **3D &amp; Motion** — parametric modeling (Rhino, Cinema 4D) + real-time web 3D with React Three Fiber
- 🎮 **Interactive experiences** — game development and high-fidelity prototyping as a creative outlet
